# Rhythm Bot Telegram

Um bot de música para o Telegram desenvolvido em Python, permitindo que os usuários interajam com funcionalidades musicais diretamente pelo aplicativo.

## Funcionalidades

- Pesquisa de músicas.
- Reprodução de músicas.
- Interação por comandos no Telegram.

## Tecnologias utilizadas

- Python
- Telegram Bot API
- Genius API



## Execução

1. Acesse o bot pelo link: (https://t.me/LyricRhythm_Bot)
2. Inicie uma conversa com o bot.
3. digite o comando:
```bash
/start
```
